# Meeting-to-Action Workspace

Teams lose decisions and follow-up tasks in long meeting recordings. Build a lightweight tool that converts a short meeting recording or transcript into a concise summary, decisions, action items, owners, and due dates when explicitly mentioned. Users must be able to edit the result before exporting it.

## Trust rules
- Owners and due dates are included only when explicitly mentioned.
- Every decision and action links to the transcript segments supporting it.
- Uncertain output stays visible as unverified for human review.
- The user edits the result before export.
- Meeting transcript and audio are sensitive; by default they are transient and purged.
