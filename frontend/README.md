# frontend

React 18 + Vite + TypeScript. Hand-written CSS in `src/styles.css` and `src/theme-polish.css`
(no Tailwind), Zustand for the editable meeting state, zod for validation, GSAP/ScrollTrigger and
Lenis for motion, lucide for icons.

## Routes

| Route | Page |
|---|---|
| `/` | landing page with the transcript-to-actions story |
| `/meet` | new meeting: paste a transcript, upload a recording, or the simulated Meet bot |
| `/meet/:id` | processing view, then the review workspace (Overview, Decisions, Actions, People, Timeline, Transcript, Ask, Recap) |

## Commands

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm run dev        # http://localhost:5173, proxies /api and /health to :8000
corepack pnpm run typecheck
corepack pnpm run lint
corepack pnpm test           # vitest
corepack pnpm run build      # dist/
```

## Browser walkthrough (Playwright)

`e2e/demo.mjs` drives the three-minute demo against a running backend and dev server. It
needs `@playwright/test` (already a dev dependency) and Chromium:

```powershell
npx playwright install chromium
$env:E2E_APP_TOKEN="<the token the backend was started with>"
node e2e/demo.mjs
```

It fails on a console error, a failed/4xx network request, a horizontal overflow at 360/768 px, a
tab-bar layout shift, or a missing/blocked export, and writes screenshots to `docs/screenshots/`.
The backend must run with `PROVIDER_CHAIN=mock` and `STT_BACKEND=mock` for the deterministic result.

## Notes

- The app token and meeting session tokens are kept in `sessionStorage`, never `localStorage`.
- Routes are lazy-loaded; the review workspace is its own chunk.
- `public/assets/categories/*.png` are generated by `scripts/keyout.py` from `raw/` (not committed).
